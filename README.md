# voice-assistant
🤖 bava– Python Voice Assistant  Jarvis is a simple Python-based personal assistant that can respond to commands using voice output and perform basic tasks such as telling the current time and opening websites.  🚀 Features  - 🔊 Text-to-speech using "pyttsx3" - 🕐 Tells the current time - 🎵 Opens Spotify - ▶️ Opens YouTube
